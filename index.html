How it works

1

Add your groups

Paste the URLs of the Facebook groups you want to post to. They're saved for next time.

2

Write your message

Type your post. If AI is enabled, this becomes a prompt — the AI writes the actual post for each group.

3

Click Post

The extension opens each group, types your message, and clicks Post. Progress bar shows each step in real time.

Works with your favorite AI

Bring your own API key. The extension calls the provider directly — no middleman.

Install in 4 steps

1
Download or clone the extension from GitHub
2
Open chrome://extensions in Chrome or Edge
3
Enable Developer mode (top right toggle)
4
Click Load unpacked → select the extension folder

The extension icon appears in your toolbar. Click it to start posting.
