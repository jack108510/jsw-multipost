Page Identity Test Lab

Verify the Facebook Page or profile selected by Amplr before you create any posting job.

Non-posting test

Choose the expected posting identity

Use “Update profiles” in the Reachr dashboard if the Page is not listed.

When supplied, Amplr opens the group composer, verifies the Page shown there, and closes it without typing or clicking Post.

!
This tool never creates a posting job. It switches identity, reads Facebook’s active identity, and—only if a group URL is supplied—opens and closes the composer without entering text, uploading media, commenting, or submitting a post.

What this checks

  1. 1Reads the expected Page/profile from the identities already synchronized with Amplr.
  2. 2Opens a temporary Facebook tab and runs the existing verified identity-switch path.
  3. 3Reads Facebook’s active identity and compares it with the expected identity.
  4. 4If a group URL was provided, opens the group composer solely to verify its acting identity, then closes the composer.

Latest result

Run a test to see the expected identity, observed identity, switching path, and optional composer verification.

Pass condition

A switch-only test passes when Facebook reports the selected identity as active. A group test passes only when the group composer also reports that same identity.

A failed verification is a safe stop condition. It should be resolved before any post is queued.
